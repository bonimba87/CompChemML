# SMILES Generation with VAEs (GRU Baseline)

This notebook explores **generative modeling for molecules** using a Variational Autoencoder.  
The model is trained on canonicalized SMILES strings and learns to **generate new molecular structures**, by sampling from a latent space and applying a transformation that ensures samples are drawn from the distribution describing the input data.

---

### Objectives
- Understand how **Variational Autoencoders** work in the context of generative AI.  
- Build a complete pipeline: tokenization → model → training → evaluation → generation.  
- Evaluate generated molecules with **validity, uniqueness, and novelty** metrics.  
- Visualize generated molecules and basic properties (logP, QED).
